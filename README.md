## O projeto tem intuito de demonstar alguns exemplos de Criptografia 

<h1>🔐 Criptografias presentes</h1>
<hr>
<h2>CIFRA DE CÉSAR</h2>
<p>É um simples deslocamento do caracter pelo valor da chave</p>
<hr>
<h2>CIFRA DE VIGENÈRE</h2>
<p>Em vez de somar um valor fixo, ele soma valores baseados em uma palavra-chave que se repete</p>
<hr>
<h2>CIFRA XOR</h2>
<p>Transforma o texto e a chave em binário e aplica a porta lógica Ou-Exclusivo (XOR)</p>
<hr>
<h2>FUNÇÃO HASH</h2>
<p>Não é criptografia reversível. Ele pega uma string e, através de multiplicações por 33 (via bit shift << 5) e somas dos caracteres ASCII, gera um número inteiro de 32 bits.</p>
<hr>
<h2>MINI RSA</h2>
<p>Baseado na dificuldade de fatorar números primos. Duas chaves são geradas: uma Pública (fator e + módulo n) para trancar, e uma Privada (fator d + módulo n) para destrancar.</p>
